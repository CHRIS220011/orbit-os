# Contributing to ORBIT-OS

Thanks for your interest in helping!

## Reporting Bugs

1. Check if the problem already exists in the [Issues](../../issues) section
2. If not, create a new issue
3. Describe:
   - ORBIT-OS version
   - Hardware (CPU, GPU, RAM)
   - Steps to reproduce
   - Expected vs actual behavior
   - Logs (`journalctl -b -p err`)

## Pull Requests

1. Fork the repository
2. Create a branch: `git checkout -b feature/my-change`
3. Make your changes
4. Commit: `git commit -m "Added ..."`
5. Push: `git push origin feature/my-change`
6. Open a Pull Request

## Code Style

- Use English for all comments and documentation
- Follow existing conventions in the repository
- Test your changes before submitting
